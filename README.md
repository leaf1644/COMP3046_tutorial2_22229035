# Tutorial 2 — M5StickC-to-ODrive Adapter

Student: Leung King Chit  
Student ID: 22229035  
Source file: `22229035_tutorial2.scad`

A parametric PETG adapter modelled in OpenSCAD with BOSL2. A drop-in M5StickC Plus2 cradle bolts to the ODrive v3.6 PCB short-edge mechanical M3 pair (38.5 mm centres). The stick body hangs off the board so USB-C, Grove, IR, and Button B stay clear.

## Build

1. Open `22229035_tutorial2.scad` in OpenSCAD (BOSL2 required).
2. Press **F6** to render, then export an STL.
3. Slice in Bambu Studio with the course Week 2 profile: **PETG, 0.2 mm layer height, 4 wall loops, 20% gyroid infill**.
4. Print sitting on the flange / floor face.

The physical print and the `.3mf` project are submitted in class, not in this repository.
